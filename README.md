Fiji/ImageJ macro for automated batch processing and ROI-based analysis of autoradiography images.

Features:
- Batch processing of .tif images
- Semi-automated ROI detection with user-defined thresholds
- Quantification of tracer and control regions
- Automated documentation output and result export

Used in: Stotz et al. "A PET reporter ligand for quantitative imaging of gene expression in the brain" Nature Biomedical Engineering 2026
Usage:
- Open image in Fiji
- Run macro
- Output: ROI and measurement results

Authors: Oliver Hihn, Sophie Stotz, Andreas Maurer
